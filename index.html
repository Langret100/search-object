⚙ 관리자 설정

게임을 열면 기본 AI와 경량 확장 AI를 미리 한 번만 준비합니다. 물건을 바꿀 때는 모델을 다시 다운로드하지 않습니다. 최초 AI 모델 다운로드에는 인터넷 연결이 필요합니다. 카메라는 GitHub Pages의 HTTPS에서 허용하세요. AI가 준비되지 않으면 제한시간이 시작되지 않습니다.

COCO 및 경량 확장 분류의 11종 추천 물품 중 행사장에 준비된 물건만 활성화하세요. 컵에는 머그컵이 포함되지만 재질이나 종류까지 항상 구분되지는 않습니다.

확장 9종은 약 55MB의 경량 이미지 분류 모델로 판별합니다. 화면 중앙에 물건을 크게 보여줘야 하며, AI가 물건의 위치를 표시하는 방식은 아닙니다. 실제 물품으로 정확도를 먼저 테스트하세요.

새 물품을 사진으로 등록하고, 카메라 화면에서 각도·배경을 바꿔 여러 장 수집하세요. 미리 학습된 MobileNet 특징을 KNN으로 분류하며 기기에 저장됩니다.

학습은 카메라가 켜진 상태에서 가능합니다. 물품당 최소 5장, 배경/다른 물건도 최소 5장을 학습해야 미션 후보에 포함됩니다.

카메라를 켠 다음 테스트를 시작하면 현재 엔진의 상위 인식 결과가 표시됩니다. 직접 학습 엔진은 학습 사진이 있어야 합니다.

📸 저장된 사진으로 모델 직접 시험

물리 카메라 없이 선택한 물품 사진을 실제 AI 모델로 분석합니다. 사진은 외부 서버로 업로드되지 않으며 모델 파일만 다운로드됩니다.

사진을 고르면 실제 AI 모델이 판정합니다.
검사 전
실제 AI 모델·카메라를 확인하려면 자가검사를 눌러 주세요. 물건을 비추고 실행하면 인식 결과가 나옵니다.
진단 전

COCO 외 9종은 MobileCLIP-S0 경량 이미지 분류(모델 파일 약 55MB)를 사용합니다. 물건은 카메라 중앙에 가까이 비춰 주세요. 모델은 최초 1회 내려받아 캐시에 저장되며, 서드파티 CDN 연결이 필요합니다. 확장 모델에 실패하면 해당 물건 9종은 자동으로 미션에서 제외되며, 기본 COCO 물건은 계속 이용 가능합니다.
